# rohit-v-raj.github.io

Personal site of Rohit Varadaraj, software engineer for ports and shipping.
Live at https://rohit-v-raj.github.io/

A single static page with no build step: `index.html` holds the markup, styles and script.

| Path | What it is |
| --- | --- |
| `index.html` | the page |
| `assets/fonts/` | Schibsted Grotesk and Newsreader, self hosted under the SIL Open Font License 1.1 (license texts included) |
| `assets/og-image.png` | the preview image shown when the link is shared on LinkedIn |
| `assets/favicon.svg` | browser tab icon |
| `files/` | the technical note on the ship ETA and berth planning project |

To edit: change `index.html` and push. GitHub Pages republishes within a few minutes.
